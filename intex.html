What is throttling

Throttling is a performance optimization technique that limits how often a function can execute over a continuous period of time. It guarantees that a target function runs at a maximum rate of once per specified time interval, regardless of how many times the event is triggered.

Why Use Throttling?

High-frequency events like window scrolling, resizing, or dragging can trigger web browser event handlers dozens of times per second. Throttling prevents application slowdowns and lag by forcing your code to update at a regular, controlled pace.
